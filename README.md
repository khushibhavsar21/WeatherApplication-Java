# Weather Application - Java

A simple Weather Application developed using Java Swing and a Weather API.

## Features

- Search weather by city name
- Displays temperature and weather conditions
- Shows humidity and wind speed
- Weather icons for different conditions
- Simple and user-friendly graphical interface

## Technologies Used

- Java
- Java Swing
- JSON Simple
- Weather API
- IntelliJ IDEA

## Project Structure

- `AppLaunch.java` - Starts the application
- `WeatherGui.java` - User interface
- `WeatherApp.java` - Fetches and processes weather data
- `src/assets/` - Weather icons and images
